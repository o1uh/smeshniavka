# Funny Bot («Смешнявка»)

Интеллектуальный Telegram-бот для группового чата с долгосрочной памятью (досье на каждого участника), анализом медиа (войсы, видео, фото, аудио, музыка с оценкой `N/100`), умным поиском в сети и гибкой ротацией множества ключей Gemini API.

## Ключевые возможности

- **Управление пулом ключей Gemini**: поддержка произвольного количества ключей (10, 20, 50+), разделение на активные и резервные, автоматический фейловер при 429, сброс квот в полночь по Pacific Time.
- **Интеллектуальный контекст**: сборка до 60 последних сообщений, экскурс по веткам реплаев, скользящее саммари и досье участников.
- **Медиа-аналитика**: распознавание речи (войсы/кружочки), OCR картинок, разбор треков через ffmpeg + inline base64 в Gemini с объективной оценкой `N/100`.
- **Защита от инъекций (Anti-Prompt-Injection)**: входящий текст людей никогда не становится системными инструкциями, экранирование тегов, санитайзинг ников, распознавание попыток взлома и едкие ответы в образе.
- **Умный ресерч**: автоматическое решение о необходимости поиска через Google Search, анонимизация запросов (без утечки имен и ников).
- **Деплой на Raspberry Pi / Linux**: автоматический скрипт `deploy.sh`, systemd unit `ops/bot.service` или Docker Compose.

## Быстрый старт (Разработка)

```bash
# 1. Установка зависимостей
uv pip install -r requirements.txt
# или: pip install -r requirements.txt

# 2. Проверка dry-run
python -m src.main --dry-run

# 3. Запуск тестов
pytest
```

## Управление ключами

Ключи хранятся в `.env` (права 600):
```env
TG_TOKEN=...
GEMINI_KEY_1=...
GEMINI_KEY_2=...
GEMINI_KEY_RESERVE=...
OWNER_IDS=123456789
```

Конфигурация лимитов — в `config/keys.yaml` (без самих секретов).
Для проверки работоспособности всех ключей:
```bash
python -m src.tools.check_keys
```
